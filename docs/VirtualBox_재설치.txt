==========================================================================
 VirtualBox 재설치 절차  (VBoxDrv 커널 드라이버 누락 해결)
==========================================================================

 [원인 확정]
   StartService: OpenService FAILED 1060
   1060 = ERROR_SERVICE_DOES_NOT_EXIST  (서비스가 존재하지 않음)

   VirtualBox 는 VBoxDrv 라는 커널 드라이버 위에서만 동작합니다.
   이 드라이버가 등록되지 않아 VM 프로세스가 뜨기도 전에 죽었고,
   그래서 VBox.log 조차 새로 만들어지지 않았습니다.

 [중요] VM 파일은 지워지지 않습니다.
        D:\Virtualbox\VMS\testVM 폴더와 그 안의 가상 디스크
        (코드, DB, 러너 설정 전부)는 그대로 보존됩니다.


--------------------------------------------------------------------------
 1단계  기존 VirtualBox 제거
--------------------------------------------------------------------------

  [Windows 키] - "앱 및 기능" 또는 "프로그램 추가/제거" 검색
    - 목록에서 "Oracle VirtualBox" 찾기 - 제거

  ※ 제거 중 "네트워크 연결이 잠시 끊길 수 있습니다" 는 정상입니다.


--------------------------------------------------------------------------
 2단계  재부팅   ← 건너뛰지 마세요
--------------------------------------------------------------------------

  드라이버는 재부팅해야 완전히 내려갑니다.
  이걸 건너뛰면 재설치해도 같은 문제가 반복됩니다.


--------------------------------------------------------------------------
 3단계  남은 드라이버 파일 삭제
--------------------------------------------------------------------------

  파일 탐색기 주소창에 아래를 붙여넣고 Enter:

      C:\Windows\System32\drivers

  검색창에 VBox 를 입력해서 나오는 .sys 파일이 있으면 전부 삭제.
  (VBoxDrv.sys, VBoxNetAdp6.sys, VBoxNetLwf.sys, VBoxUSBMon.sys 등)

  ※ 없으면 그냥 넘어가세요. 정상입니다.
  ※ "권한이 필요합니다" 가 뜨면 [계속] 을 누르세요.


--------------------------------------------------------------------------
 4단계  재설치   ★ 여기가 가장 중요합니다
--------------------------------------------------------------------------

  다운로드: https://www.virtualbox.org/wiki/Downloads
            - "Windows hosts" 클릭

  ★★ 설치 파일을 더블클릭하지 마세요.
      반드시 [마우스 우클릭] - [관리자 권한으로 실행]

      일반 실행하면 프로그램은 설치되는데 커널 드라이버 등록만
      조용히 실패합니다. 이번 문제의 원인일 가능성이 높습니다.

  설치 도중 이런 창이 뜹니다:

      "이 장치 소프트웨어를 설치하시겠습니까?"
      게시자: Oracle Corporation

  → 반드시 [설치] 를 누르세요. [설치 안 함] 을 누르면
    지금과 똑같은 상태가 됩니다.

  ※ 이 창이 여러 번 뜰 수 있습니다. 매번 [설치].
  ※ 창이 다른 윈도우 뒤에 숨는 경우가 있으니
     설치가 멈춘 것처럼 보이면 작업표시줄을 확인하세요.

 5단계  재부팅
--------------------------------------------------------------------------


--------------------------------------------------------------------------
 6단계  드라이버 등록 확인
--------------------------------------------------------------------------

  [Windows 키] - "cmd" - 우클릭 - "관리자 권한으로 실행"

      sc query VBoxDrv

  이렇게 나오면 성공:

      SERVICE_NAME: VBoxDrv
      STATE       : 4  RUNNING

  "지정된 서비스가 설치된 서비스로 존재하지 않습니다" 가 나오면
  4단계에서 관리자 권한 또는 [설치] 버튼을 놓친 것입니다.
  1단계부터 다시 하세요.


--------------------------------------------------------------------------
 7단계  기존 VM 다시 등록
--------------------------------------------------------------------------

  VirtualBox 실행 - 상단 메뉴 [머신] - [추가]

      D:\Virtualbox\VMS\testVM\testVM.vbox

  선택하면 목록에 testVM 이 다시 나타납니다.
  (새로 만들지 마세요. 기존 디스크를 그대로 씁니다)


--------------------------------------------------------------------------
 8단계  포트 포워딩 확인
--------------------------------------------------------------------------

  재등록하면 설정은 대부분 따라오지만, SSH 포트 포워딩은
  한 번 확인하는 게 좋습니다.

  VM 선택 - [설정] - [네트워크] - [어댑터 1] - [고급] - [포트 포워딩]

      이름  프로토콜  호스트IP    호스트포트  게스트IP  게스트포트
      ssh   TCP       127.0.0.1   2222        (비움)     22

  없으면 [+] 로 추가하세요.


--------------------------------------------------------------------------
 9단계  시작
--------------------------------------------------------------------------

  VM 선택 - [시작]

  부팅되면 30초 뒤 내 PC 의 CMD 에서:

      ssh -p 2222 vboxuser@127.0.0.1

  접속되면 (프롬프트가 vboxuser@ubuntu:~$ 로 바뀐 뒤):

      cd ~/Liinux-
      git pull
      sudo ./scripts/setup_autoheal.sh

  이걸로 대기 중이던 배포가 자동 진행되고,
  앞으로는 재부팅/터널끊김에 손댈 일이 없어집니다.


==========================================================================
 참고 — 그래도 VBoxDrv 가 등록되지 않는다면
==========================================================================

  다음 중 하나가 드라이버 설치를 막고 있을 수 있습니다.

  1) 백신/보안 프로그램
       설치하는 동안만 잠시 중지한 뒤 4단계를 다시 하세요.

  2) Windows 드라이버 서명 강제
       관리자 CMD 에서 확인:
           bcdedit | findstr /I "testsigning nointegritychecks"
       값이 On 이면 오히려 서명된 드라이버가 거부될 수 있습니다.
           bcdedit /set testsigning off
           bcdedit /set nointegritychecks off
       후 재부팅.

  3) 회사 관리 PC 정책
       그룹 정책으로 드라이버 설치가 차단된 경우 사용자가
       해결할 수 없습니다. 이때는 VirtualBox 대신 WSL2 사용을
       검토해야 합니다 (단, Hyper-V 를 다시 켜야 합니다).
